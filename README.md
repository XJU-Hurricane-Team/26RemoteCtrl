### 硬件信息

主控芯片为STM32F429VET6（ROM：512.0KB RAM：192.0KB）

使用PS5遥感，ADS8688芯片采集电压，屏幕采用240*320分辨率SPI接口St7789主控的LCD屏。



### 开发环境

工程基于[战队模板搭建](https://github.com/XJU-Hurricane-Team/STM32-Template)，使用 CubeMX 生成底层驱动，VScode EIDE 插件组织，AC6 编译。



硬件详细信息见：[F4-ADS遥控器 - XJU-Hurricane-docs](https://xju-hurricane-team.github.io/Circuit/其他/F4-ADS遥控器/#_1)

TouchGFX 参阅：[介绍 | TouchGFX Documentation](https://support.touchgfx.com/zh-CN/docs/category/introduction)
